## 评审来源

项目负责人已确认评审通过。课程教师姓名、课堂签字和其他组提问记录由实际评审材料补充。当前评审记录保存文档核验、需求一致性及交付验证的依据。

## 三项评审标准

| 标准 | 检查对象 | 判据与结果 |
| --- | --- | --- |
| 可测试 | 24 条故事与 16 项需求 | 故事逐条包含 Given/When/Then；性能、安全、可用性给定环境、数量、目标及计时口径；实际验收与目标分别记录 |
| 完整 | 17 个用例、参与者、主备选流、证据 | 每个用例关联需求；覆盖个人用户与演示测试参与者、推理与沙箱服务；访谈和试用仍按真实采集补证 |
| 一致 | 状态、时限、权限、倍率与费用 | 生命周期和模型等待分开取数，容量回执保持原身份前提明确；查询两秒目标与任务生成时长分别计量；16× 按会话 / 槽位解释 |

## 关键核对

| 项目 | 采用的规格 |
| --- | --- |
| 查询与长操作 | 1000 次 GET 的 P95 两秒；模型、工具、恢复、排队各有实际时长 |
| 等待与休眠 | 真实模型或闲置事件触发成本决策，动作遵守工具安全点 |
| 重试与未知结果 | 相同已完成操作复用原回执；未知结果沿原身份核对 |
| 容量等待 | 首次准入与恢复分别计量，WAITING_CAPACITY 来源为恢复回执 |
| 租户与实验数据 | 个人页面按授权租户取数，全局实验在独立受控环境演示 |
| 文件与进程连续性 | 本地 VOLUMES 校验文件；真实 MEMORY 同时校验进程标记 |
| 原项目数字 | 64 / 4、16×、50/50 trial、14,400/14,400 请求保留环境与基线口径 |
| 需求与实现 | SRS 是验收目标，故事标注已有基础和课程待交付部分 |
