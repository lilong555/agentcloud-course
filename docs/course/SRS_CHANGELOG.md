# SRS 变更记录

## v1.0 · 2026-11-27

AgentCloud 个人 AI 云端工作台的首个需求基线，包含九项功能需求、七项非功能需求、24 条用户故事和 17 个用例。

功能范围为多工位、任务提交、工具结果、文件操作、智能休眠与恢复、容量等待、资源看板和受控策略对照；费用估算作为 P1 增强项。质量要求覆盖一致性、联合评价、可复现、易用性、性能、安全及可用性。

基线同时提供主备选场景、需求与用例追溯、证据索引、需求变更模板、评审记录和下次课分析模型草稿。已有后端能力与课程实现目标在故事 Issue 标记，历史数据保留来源和运行条件。

评审依据见 [REVIEW.md](REVIEW.md)。后续变更按[需求变更流程](CHANGE_CONTROL.md)关联 Issue、PR 与新版本记录。
