# 团队分工

课程组按 4–5 人组建，角色可兼任。当前仓库维护账号为 [@lilong555](https://github.com/lilong555)，课程成员和主责由组队结果确定。

| 角色 | 职责 | GitHub 账号 / 认领状态 |
| --- | --- | --- |
| 组长 | 选题、需求确认、计划、评审安排与课堂讲解 | 待成员认领 |
| AI 使用负责人 | 记录 AI 辅助范围、检查引用和人工核验记录 | 待成员认领 |
| DevOps 负责人 | 环境、CI、分支保护、部署与演示复现 | 待成员认领 |
| 测试负责人 | 状态正确性、配对实验协议、资源与时延指标和测试结果 | 待成员认领 |
| 算法开发负责人 | 高密度运行、等待与成本调度、容量排队分析；4 人组可兼任 | 待成员认领 |

成员通过 Issue 认领工作并在 PR 中提交成果。组长确认主责与协作人后更新本表；任务验收由另一位成员参与，GitHub 评审记录关联相应交付物。
